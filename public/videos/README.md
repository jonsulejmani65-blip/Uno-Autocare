# Hero-Video

Lege hier das finale Hero-Video unter dem Dateinamen `uno-autocare-hero.mp4` ab:

```
public/videos/uno-autocare-hero.mp4
```

Es wird automatisch im Hero-Bereich der Startseite eingebunden
(`src/components/home/Hero.tsx`). Bis dahin zeigt die Seite einen
hochwertigen Gradient-Platzhalter.

Empfehlungen für das Video:
- Format: MP4 (H.264), 16:9 oder 9:16 responsive
- Dauer: ca. 10–20 Sekunden, nahtlos loopbar
- Ohne Ton (das Video wird `muted` abgespielt)
- Komprimiert für Web (idealerweise < 8–10 MB für schnelle Ladezeiten)
